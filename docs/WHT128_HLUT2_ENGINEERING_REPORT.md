| Candidate 2-Bit Format | Effective `bpw` | Exact Failure Mode Across `Blackhole P150A` (Tensix SRAM) & `MI50` (`gfx906`) |

| **Unrotated Hardware `Bfp2_b` (`16`-datum shared exp)** | `2.50` | **(1) Numerical collapse:** Unrotated channel outliers collapse `SwiGLU` cosine to `0.729`. **(2) Blackhole LLK bugs:** Native `Bfp2_b` paths hit TT-Metal issues ([`#58712`](https://github.com/tenstorrent/tt-metal/issues/58712), [`#56682`](https://github.com/tenstorrent/tt-metal/issues/56682), [`#57683`](https://github.com/tenstorrent/tt-metal/issues/57683)). **(3) Capacity overflow:** Exceeds `160 GiB` DRAM by `24.6 GiB`. |
| **`WHT128-HLUT2` (Ours, [`PolarQuant` Lloyd-Max](https://arxiv.org/html/2603.29078v1))** | **`2.125`** | **Zero LUT gathers, zero sequential state, zero `Bfp2_b` bugs:** Orthonormal `WHT128` Gaussianizes `128`-wide blocks and symmetric 2-bit centroids collapse into a **branchless 1-bit affine FMA** on both Tensix `SFPU` ($\to$ L1 `Bfp8_b` $\to$ `FP32` `Dst`) and `gfx906` (`v_dot2_f32_f16`). |

For each `128`-element block $b$ with deterministic Rademacher sign vector $s_b \in \{\pm 1\}^{128}$, orthonormal Walsh-Hadamard rotation $Q_b = \frac{1}{\sqrt{128}} H_{128} \operatorname{diag}(s_b)$ preserves inner products while Gaussianizing weights to $\mathcal{N}(0, \sigma_{r,g}^2 I_{128})$ (`0.125 bpw` scale). Symmetric [`PolarQuant`](https://arxiv.org/html/2603.29078v1) centroids $\{-c_1, -c_0, +c_0, +c_1\}$ (`c0 = 0.452780`, `c1 = 1.510417`) decode via a branchless 1-bit affine FMA:

$$\hat{w}(s, m) = (-1)^s \cdot \sigma_{r,g} \cdot \bigl(c_0 + m \cdot (c_1 - c_0)\bigr), \qquad H_{\text{bal}} = \frac{H_{\text{common}} + \lambda H_{\text{rare}}}{M_{\text{cal}}} + 0.015\,\bar{d}\,I_K, \qquad \lambda = \frac{\operatorname{tr}(H_{\text{common}})}{\operatorname{tr}(H_{\text{rare}})}$$

This mirrors [`Thinking Machines Lab`'s `End-to-End 4-Bit Training`](https://thinkingmachines.ai/blog/end-to-end-4-bit-training/) Randomized Hadamard Transform outlier suppression while extending [`QuIP#` `LDLQ`](https://arxiv.org/html/2402.04396v1) + [`TARQ` `RAREBAL`](https://arxiv.org/pdf/2605.27808) trace equalization across **`561` hot experts** (`3× MI50` `rocblas_dgemm` `FP64` blocked Cholesky at `1.51 s/expert`, `561/561` Dual-Receipt pass, `34/34` `P150A` L1 shards, `mean cos 0.88357 → 0.95228`, `+4.221 dB` SNR; Layer 6 Expert 0 ablation: `0.72958` absmax $\to$ `0.83828` `H=I` $\to$ `0.96881` `LDLQ` $\to$ **`0.97472`** `RAREBAL-LDLQ`, `+13.02 dB`, `-24.7%` rare MSE).
